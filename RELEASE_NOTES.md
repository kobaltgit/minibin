# MiniBin v2.0.1 🗑️✨

**MiniBin v2.0.1** включает встроенную систему проверки обновлений через GitHub Releases API, защиту от превышения лимитов запросов, системные уведомления Windows Toast, а также новый раздел **«О программе»** в контекстном меню трея и интерфейсе Flyout.

---

## 🌟 Что нового в версии 2.0.1 / What's New

### 🔄 Проверка обновлений (GitHub Releases API)
* **Автопроверка при старте:** запускается в фоновом потоке через 3 секунды после старта системы, не замедляя запуск Windows.
* **Защита от лимитов (Rate Limit Cooldown 1 час):** если приложение перезапускается часто, повторные запросы к GitHub API блокируются на 1 час.
* **Периодический опрос:** автоматическая проверка раз в неделю при непрерывной работе.
* **Системные уведомления Windows Toast:** при выходе новой версии всплывает нативное уведомление Windows 10/11 (показывается только один раз для каждой новой версии).
* **Индикатор обновления:** в шапке окна появляется пульсирующий бейдж с номером версии, ведущий сразу к загрузке.
* **Интерактивная ручная проверка:** кнопка «Проверить обновления» со спиннером и прямыми ссылками на скачивание `.exe` / `.zip`.

### ℹ️ Раздел «О программе» (About MiniBin)
* **Пункт меню трея «О программе...»:** мгновенно открывает окно программы, переключает на вкладку настроек и мягко подсвечивает карточку.
* **Информация и ссылки:** логотип, градиентный бейдж `v2.0.1`, ссылки на [Официальный сайт](https://kobaltgit.github.io/minibin/), репозиторий GitHub, страницу баг-репортов и лицензию MIT.
* **Авторство:** *Разработка: kobaltgit • Оригинальная идея: King Triton*.

### 🌐 Обновление сайта
* Промо-сайт обновлён актуальными ссылками на установщик и portable-версию v2.0.1.
